Privacy Policy

Effective date: June 1, 2026

Solana Reply Generator is a small web app and Chrome extension that generates short replies for Tweet/X status links. We do not intentionally save user data. This policy explains the limited data that is processed only to provide the reply-generation feature.

Information We Collect

We do not require an account, and we do not ask for your name, email address, payment information, contacts, location, browsing history, or authentication credentials. We do not intentionally store generated replies, Tweet URLs, tweet IDs, or extracted Tweet context in an application database.

When you generate a reply, the app or extension may send the following information to our API:

  • The Tweet/X URL or tweet ID you provided or right-clicked.
  • Tweet embed text and author information fetched from X's public oEmbed endpoint for that Tweet URL.
  • Basic request metadata may be processed transiently by infrastructure providers, such as IP address, user agent, request path, timestamps, and error logs.

How We Use Information

We use this information only to generate the requested reply, operate the service, debug failures, prevent abuse, and maintain reliability. We do not use it to build user profiles, track users across sites, or personalize advertising.

The Chrome extension uses its permissions only when you choose Create Solana reply from the right-click menu. It does not read arbitrary page content, track browsing history, inject scripts into pages, or run in the background to monitor websites.

Sharing and Service Providers

To provide the reply-generation feature, the API may share the Tweet URL, tweet ID, extracted public Tweet context, and prompt text with:

  • OpenRouter, which routes the prompt to an AI model and returns generated text.
  • X / Twitter oEmbed, which returns public embed data for the Tweet URL.
  • Vercel, which hosts the website and API and may process request logs and operational metadata.

We do not sell user data, save generated replies for later use, use user data for advertising, or share it with data brokers.

Chrome Extension Permissions

  • contextMenus: used to add the right-click action that starts reply generation.
  • tabs: used only to open X's reply composer or the Solana Reply Generator fallback page in a new tab.
  • https://solanareplygenerator.lol/*: used only to call our reply-generation API.

Remote Code

The Chrome extension does not load or execute remotely hosted code. All JavaScript executed by the extension is packaged inside the extension. API responses are treated as data and are not executed as code.

Data Retention

We do not intentionally save user data, maintain user accounts, or maintain a user database for generated replies. Hosting and service providers may process temporary operational logs according to their normal practices, but Solana Reply Generator does not use those logs to identify users, profile users, or retain generated reply history.

Security

Requests to the website, API, and extension API endpoint use HTTPS. No method of transmission or hosting is perfectly secure, but we limit permissions and data use to what is needed for the user-facing reply-generation feature.

Your Choices

You can avoid sending Tweet context by not using the generation feature. You can uninstall or disable the Chrome extension at any time from Chrome's extensions page.

Children

Solana Reply Generator is not directed to children under 13, and we do not knowingly collect personal information from children.

Changes

We may update this policy as the product changes. The effective date above will be updated when material changes are made.

Contact

For privacy questions, contact us through the support contact listed in the Chrome Web Store listing or open an issue at github.com/water-bear86/solreplies/issues.

Chrome Web Store Limited Use Disclosure

The use of information received from Chrome APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.
